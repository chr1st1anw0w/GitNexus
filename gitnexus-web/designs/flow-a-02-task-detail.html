Implement Impact Analysis Dashboard

Build a dedicated dashboard view within GitNexus AI Hub that visualizes the blast radius of any symbol change — surfacing direct callers (d=1), indirect dependents (d=2), and transitive chains (d=3) in an interactive graph. The panel must consume the gitnexus_impact MCP tool response and render risk levels with color-coded severity.

Acceptance Criteria

  • Sidebar panel opens on clicking any symbol in the code explorer
  • Calls gitnexus_impact({target, direction: "upstream"}) and renders response
  • Color-coded risk rings: CRITICAL (red), HIGH (amber), MEDIUM (blue), LOW (muted)
  • Graph nodes are clickable — click expands that symbol's own impact tree
  • "Export Impact Report" button generates a Markdown summary
  • Loading skeleton shown while MCP call is in flight (<300ms threshold)
  • Responsive down to 1280px viewport width without horizontal scroll
