Buttons 按鈕設計提示詞

設計一個現代化的按鈕元件系統，具備以下特性： 【設計規格】 - 圓角：12px (rounded-xl) - 內距：水平 16px，垂直 8px (px-4 py-2) - 字體：14px, font-semibold - 邊框：1px solid, 透明度 30% - 背景：半透明漸層 (opacity 10%) - 過渡動畫：200ms ease 【顏色變體】 1. Primary (Cyan) - 邊框色：#22D3EE (30% opacity) - 背景色：#06B6D4 (10% opacity) - 文字色：#CFFAFE - Hover: 背景 opacity 提升至 20% 2. Warning (Amber) - 邊框色：#FBBF24 (30% opacity) - 背景色：#F59E0B (10% opacity) - 文字色：#FDE68A 3. Danger (Rose) - 邊框色：#FB7185 (30% opacity) - 背景色：#F43F5E (10% opacity) - 文字色：#FECDD3 4. Success (Emerald) - 邊框色：#34D399 (30% opacity) - 背景色：#10B981 (10% opacity) - 文字色：#D1FAE5 5. Ghost (Neutral) - 邊框色：#2A2A3E - 背景色：#1A1A2E (50% opacity) - 文字色：#A0A0B8 - Hover: 文字色變為 #FFFFFF 【尺寸變體】 - Small: px-3 py-1.5, text-xs - Medium (default): px-4 py-2, text-sm - Large: px-6 py-3, text-base 【形狀變體】 - Rounded: rounded-xl (12px) - Pill: rounded-full (9999px) 【Mock Up 範例】 - "Get Started" (Primary, Medium) - "Learn More" (Ghost, Medium) - "Delete" (Danger, Small) - "Confirm" (Success, Large)

Cards 卡片設計提示詞

設計一個靈活的卡片元件系統，用於資訊展示與分組： 【基礎規格】 - 圓角：24px (large cards), 16px (medium cards) - 內距：24px (p-6) for large, 16px (p-4) for medium - 邊框：1px solid #2A2A3E - 陰影：2xl shadow with black/20 opacity (for modals) 【背景變體】 1. Deep Card (主要內容) - 背景色：#0F0F1E (80% opacity) - 用途：主要內容區域、大型面板 - 類別：rounded-3xl border border-border-subtle bg-deep/80 p-6 2. Surface Card (次要內容) - 背景色：#1A1A2E (40% opacity) - 用途：嵌套元素、次要資訊 - 類別：rounded-2xl border border-border-subtle bg-surface/40 p-4 3. Accent Card (高亮提示) - 邊框色：#22D3EE (20% opacity) - 背景色：#06B6D4 (10% opacity) - 文字色：#CFFAFE - 用途：重點訊息、互動狀態 4. Warning Card - 邊框色：#FBBF24 (20% opacity) - 背景色：#F59E0B (10% opacity) - 文字色：#FDE68A - 用途：警告提示 【層次結構】 - Level 1 (最外層): Deep Card, rounded-3xl, p-6 - Level 2 (嵌套): Surface Card, rounded-2xl, p-4 - Level 3 (內容): Info Panel, rounded-xl, p-3 【Mock Up 範例】 標題：Explorer Canvas 內容：「Hover for preview, click to inspect, and right-click a hovered node to open the context menu.」 區塊數量：3-4 個嵌套卡片

完整設計系統提示詞 (Master Prompt)

# GitNexus Design System - Complete Specification 建立一個現代化、專業的深色主題設計系統，用於程式碼視覺化與分析平台。 ## 核心設計原則 - 深色背景，高對比度文字 - 半透明層疊效果 (glassmorphism) - 柔和的漸層與邊框 - 清晰的視覺層次 - 一致的圓角與間距 ## 顏色系統 ### 主色調 (Primary) - Cyan 400: #22D3EE (強調色) - Cyan 500: #06B6D4 (主要互動) - Accent: #667EEA (次要強調) ### 狀態色 (Status) - Success: #10B981 (emerald-500) - Warning: #F59E0B (amber-500) - Danger: #F43F5E (rose-500) - Info: #22D3EE (cyan-400) ### 背景層級 - Background Deep: #0A0A14 (最底層) - Deep: #0F0F1E (主要容器) - Void: #000000 (畫布背景) - Surface: #1A1A2E (卡片、面板) ### 文字顏色 - Primary: #FFFFFF (主要內容) - Secondary: #A0A0B8 (說明文字) - Muted: #6B6B7F (標籤、提示) ### 邊框 - Border Subtle: #2A2A3E (預設邊框) - Border Accent: 各狀態色 + 20-30% opacity ## 間距系統 (Tailwind Scale) - 1 → 4px - 2 → 8px - 3 → 12px - 4 → 16px - 5 → 20px - 6 → 24px - 8 → 32px ## 圓角系統 - rounded-xl: 12px (按鈕) - rounded-2xl: 16px (卡片元件) - rounded-3xl: 24px (大型卡片) - rounded-full: 9999px (徽章) ## 字體系統 - H1: 30px, font-black, tracking-tight - H2: 20px, font-semibold - H3: 14px, font-semibold, uppercase, tracking-[0.18em] - Body: 14px, leading-6 - Caption: 12px, font-semibold, uppercase ## 元件規格 ### Buttons ``` Primary (Cyan): - border: border-cyan-400/30 - bg: bg-cyan-500/10 - text: text-cyan-200 - rounded: rounded-xl - padding: px-4 py-2 Variants: Warning (amber), Danger (rose), Success (emerald), Ghost (neutral) ``` ### Cards ``` Deep Card: - border: border-border-subtle - bg: bg-deep/80 - rounded: rounded-3xl - padding: p-6 Surface Card: - bg: bg-surface/40 - rounded: rounded-2xl - padding: p-4 ``` ### Badges ``` Status Badge: - shape: rounded-full - padding: px-3 py-1 - font: text-xs font-semibold uppercase tracking-[0.2em] - border + bg gradient (30% + 10% opacity) ``` ### Panels ``` Info Panel: - bg-surface/40 - border-border-subtle - rounded-2xl - p-4 Highlight Panel: - border-cyan-400/20 - bg-cyan-500/10 - text-cyan-100 ``` ## 互動狀態 - Hover: opacity 提升、文字顏色變亮 - Active: 背景加深、邊框增強 - Disabled: opacity 50%, cursor not-allowed - Focus: ring-2 ring-accent/50 ## 動畫 - Transition: 200ms ease - Hover effects: transform scale(1.02) - Fade in: opacity 0→1, 300ms ## Mock Up 內容建議 ### 標題 - "GitNexus Web Interactive Demo" - "Explorer Canvas" - "Impact Analysis Dashboard" ### 按鈕文字 - "Get Started", "Learn More", "Run Analysis" - "Open Inspector", "Focus Node", "Clear" ### 狀態徽章 - "ACTIVE", "SUCCESS", "WARNING", "HIGH RISK" - "DEMO MODE", "LIVE DATA" ### 標籤 - "React", "TypeScript", "Graph Visualization" - "AI-Powered", "Real-time", "Interactive" ### 數字 Mock Up - 節點數量：1,234 - 風險分數：87% - 影響範圍：d=1 (42), d=2 (128) ## 設計建議 1. 保持深色背景的一致性 2. 使用半透明層疊創造深度感 3. 限制主色調為 2-3 種 4. 確保高對比度（WCAG AA 以上） 5. 使用微妙的動畫提升互動體驗
