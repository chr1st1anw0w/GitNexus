# NotebookLM Source Analysis & Verification

Comprehensive analysis of information sources, credibility assessment, and content evaluation.

## Core Capabilities

### Source Evaluation
- **Credibility assessment**: Evaluate source reliability and authority
- **Bias detection**: Identify potential biases and perspectives
- **Currency analysis**: Assess information timeliness and relevance
- **Cross-referencing**: Verify claims against multiple sources

### Content Analysis
- **Fact checking**: Verify factual claims and statements
- **Logical analysis**: Evaluate arguments and reasoning
- **Evidence quality**: Assess supporting evidence strength
- **Gap identification**: Find areas needing additional verification

## Usage Patterns

### When to Use
- Evaluating research papers and academic sources
- Verifying technical documentation accuracy
- Assessing news articles and industry reports
- Reviewing vendor claims and marketing materials
- Analyzing code comments and documentation

### Analysis Types
- **Academic evaluation**: Methodology, peer review status, citation analysis
- **Technical assessment**: Implementation accuracy, best practice compliance
- **Business analysis**: Market claims, competitive positioning
- **Security review**: Vulnerability assessments, threat analysis

## Commands & Features

### Source Analysis
```bash
# Analyze source credibility
notebooklm analyze-source "research-paper.pdf" --criteria "methodology,peer-review,impact"

# Fact check specific claims
notebooklm fact-check "AI will replace all jobs by 2030" --sources "multiple"

# Evaluate documentation quality
notebooklm evaluate-docs "api-documentation.md" --standards "completeness,accuracy,usability"
```

### Content Verification
```bash
# Cross-reference information
notebooklm cross-reference "climate-change-data" --sources "ipcc,nasa,noaa"

# Bias detection
notebooklm detect-bias "product-review.pdf" --perspective "neutral"

# Currency assessment
notebooklm check-currency "technology-trends.pdf" --benchmark "2024"
```

## Evaluation Frameworks

### Credibility Metrics
- **Authority**: Source expertise and reputation
- **Accuracy**: Factual correctness and precision
- **Objectivity**: Freedom from bias and conflicts of interest
- **Currency**: Information timeliness and updates
- **Coverage**: Scope and depth of information

### Quality Assessment
- **Completeness**: Information comprehensiveness
- **Consistency**: Internal logical consistency
- **Relevance**: Alignment with intended purpose
- **Usability**: Ease of understanding and application

## Specialized Analysis Types

### Academic Research
- **Methodology review**: Research design and execution quality
- **Statistical analysis**: Data validity and statistical methods
- **Citation evaluation**: Reference quality and completeness
- **Peer review assessment**: Review process rigor

### Technical Documentation
- **Implementation accuracy**: Code examples and technical details
- **Best practice compliance**: Industry standards adherence
- **Version compatibility**: Technology version considerations
- **Security implications**: Potential security concerns

### Business Intelligence
- **Market data validation**: Market size and growth claims
- **Competitive analysis**: Positioning and differentiation claims
- **Financial projections**: Assumption validity and realism
- **Risk assessment**: Identified and unstated risks

## Verification Workflows

### Multi-Step Verification
1. **Initial assessment**: Quick credibility evaluation
2. **Cross-referencing**: Compare with multiple sources
3. **Evidence review**: Examine supporting data and logic
4. **Context consideration**: Evaluate broader implications
5. **Confidence scoring**: Assign reliability ratings

### Automated Checks
- **Fact verification**: Cross-reference with known databases
- **Citation validation**: Check reference accuracy
- **Date verification**: Confirm timeline accuracy
- **Source authentication**: Verify publisher legitimacy

3. **Bias awareness**: Consider potential conflicts of interest
4. **Timeliness assessment**: Verify information currency for domain
5. **Expertise matching**: Match source credibility to claim complexity
